Components / Actions

Buttons
& actions

最小 44px 点击区、按下 0.96、focus-visible、触摸端不依赖 hover。复制 HTML 即可用；颜色通过 --mk-* 覆盖。

Variants

mk-btn · primary · ghost · glass

玻璃按钮需要深色/复杂背景；纯白背景上看不见 blur，不要用。

Sizes & icons

44px 最小点击区

图标按钮必须有 aria-label；不要用纯图标表达关键操作。

Feedback

磁吸 · 涟漪 · 触感 · 加载

磁吸只在 (hover:hover) and (pointer:fine) 启用；触摸端自动退化为按压。

States

default / focus / pressed / disabled

Default

44px 高，圆角 999px，主色背景。

Focus

Tab 聚焦时出现 :focus-visible 焦点环。

Pressed

scale(.96)，给手指/鼠标即时反馈。
