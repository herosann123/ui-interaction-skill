# Design Core · 规则

> 从 `ui-layout-skill` / `ui-visual-skill` / `ui-component-skill` / `ui-verify-skill`
> 抽取的可执行部分；完整方法论仍在原 skill。这里只保留会直接影响生成结果的规则。

## 1. 五条硬约束（违反即改）

1. **无横向溢出**：任何视口 `scrollWidth ≤ clientWidth`（实测，非目测）。
2. **正文行长 45–75ch**：超过就分栏或加宽边距；`--prose: 68ch`。
3. **触控目标 ≥ 44×44px**：手机/平板所有可点元素。
4. **间距出自同一 scale**：`tight / normal / loose` 三选一，全站统一，不混随机值。
5. **视觉层级 ≤ 4 层**：一屏字号权重档位超过 4 层 = 没有层级。

## 2. 三个布局决策问题

1. **信息优先级**：第一眼必须看到什么？第二眼呢？
2. **阅读动线**：线性（文章）、并列（商品/功能）、探索（画廊/叙事）？
3. **内容密度**：一屏 3 个元素还是 30 个？决定 spacing 档位与列数。

## 3. 间距三档

| 档位 | 阶梯 | 适合 |
|---|---|---|
| tight | 4 / 8 / 12 / 16 / 24 / 32 / 48 | 仪表盘、工具、数据密集 |
| normal | 8 / 16 / 24 / 32 / 48 / 64 / 96 | 大多数营销页、官网 |
| loose | 12 / 24 / 36 / 48 / 72 / 96 / 144 | 高端品牌、画廊、留白型 |

## 4. 排版

- 字号比 ≈ 1.25；全页 ≤ 7 级。
- 字重对比 > 字号对比 > 字距对比；不要全用 400/500 中间档。
- Eyebrow：10–11px + 0.24–0.4em 字距 + uppercase。
- 正文 14–15px，行高 1.7–1.9；长文宁大勿小。
- 数字用 `tabular-nums`；中文不用伪斜体。
- 字族 ≤ 2（+1 mono）；CJK fallback 必须写全。

## 5. 色彩纪律

- 不用纯黑 / 纯白；用带色温的 ink / bg。
- 文字层级用同一 ink 的透明度阶梯（72% / 52%），不另调多个灰。
- accent 每屏 ≤ 2 处；面积 ≤ 10%。
- 渐变只在同色相 / 邻近色相；彩虹渐变 = 禁。
- 正文对比 ≥ 4.5:1；大字 / UI ≥ 3:1。
- 阴影用 ink 色低透明度，不用默认黑；大而软 > 小而硬。
- 描边、阴影、渐变三选一，不叠加。

## 6. 组件 8 态

| 状态 | 必须表达 |
|---|---|
| default | 可点击的视觉暗示 |
| hover | 仅 `hover:hover` 设备；可点击确认 |
| focus | `:focus-visible` 清晰焦点环 |
| active | 按下即时反馈（scale / 加深） |
| disabled | 降透明 + `cursor: not-allowed` + 原因 |
| loading | 进行中 + 禁止重复提交 |
| error | 颜色 + 文字 + 图标三重提示 |
| success | 确认反馈 + 下一步 |

表单：单字段 blur 后校验；提交全量校验；输入中不清错误（改回合法才清）；
错误文字说“怎么修”；提交防重；输入字号 ≥16px。

## 7. 页面四态

`loading → content OR empty OR error`；成功给下一步入口。

- loading：骨架屏 > spinner；布局占位防跳动
- empty：解释为什么空 + 一个出口
- error：发生了什么 + 重试 + 兜底
- success：明确确认 + 下一步

## 8. 验收矩阵

| 档位 | 视口 | 重点 |
|---|---|---|
| 手机 | 390×844（次选 320×568） | 溢出、44px、单列、横滑 |
| 平板 | 768×1024 | 断点翻转、栅格退化 |
| 桌面 | 1280×800 | hover、桌面专属模式 |

每项结论四态：✅ 通过 / ❌ 未通过 / ⚠️ 未验证 / ➖ 不适用。

## 9. 廉价感速查

- 全 400/500 字重；uppercase 不加字距；中文伪斜体
- 默认 Tailwind 蓝；彩虹渐变按钮 + 大圆角 + 重阴影
- 纯黑 on 纯白；灰底灰字；一屏 3+ accent
- 长正文居中；描边 + 阴影 + 渐变同时上
- 图标/emoji 当装饰撒一屏
