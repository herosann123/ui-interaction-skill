# 反模式与性能预算

> 从 `SKILL.md` §7–§8 拆出的完整清单；章节编号保持原样。
> 每条反模式都不是永久审美禁令：先看任务、设备与证据。

## 7. 反模式（必须避免）

### 6.1 错配模块

- ❌ **长文阅读页用视差** → 影响阅读、引起眩晕
- ❌ **移动端小按钮用磁吸** → 触摸坐标不稳定，效果不可靠
- ❌ **文字密集卡片用 3D 倾斜** → 抖动影响可读性
- ❌ **关键 CTA 用文字揭示** → 用户找不到入口，转化率下降
- ❌ **列表项加 hover 动效** → 鼠标划过整列抖动，烦躁
- ❌ **用 spring 做全局导航过渡** → 太慢，体感像卡顿
- ❌ **玻璃拟态用在纯白背景** → 看不见，blur 没意义
- ❌ **SVG 路径动画在 final state 不复位** → 动画结束后虚线错位
- ❌ **极光渐变和粒子网络同时挂在一屏** → GPU 占用爆炸，移动端必卡
- ❌ **粘性堆叠超过 5 屏** → 滚动疲劳，掉帧，移动端尤其明显
- ❌ **AI 打字机不用 setState 而是 innerHTML 整段写入** → 失去"流式"灵魂
- ❌ **水波纹从按钮中心发出** → 廉价感，违反用户预期
- ❌ **FLIP 共享元素不提供稳定 key/id** → 浏览器无法定位，动画失败
- ❌ **自定义光标没在移动端禁用** → 触摸设备光标定位错乱，体验崩
- ❌ **水平滚动叙事的滚轮不 pin 容器** → 内容还没滚完就被甩走
- ❌ **噪点纹理每帧全屏重绘** → 帧率爆炸，必须用 0.5x 分辨率 canvas
- ❌ **Glitch 全程持续抖动** → 用户视觉疲劳，3 秒后只剩厌恶
- ❌ **Cmd+K 没有 Esc 关闭** → 用户被困在面板里
- ❌ **Blob Morph 的两个 path 点数不同** → GSAP 无法插值，形态直接跳变
- ❌ **滚动驱动数字忘开 tabular-nums** → 数字宽度变化引起布局抖动
- ❌ **JS 动态创建的元素挂渐入类(如 .rv)** → 滚动观察器在它诞生前就已收集完毕,永远没人观察它,元素**永久隐形**;渐入必须挂在静态父容器上,子项跟随容器状态入场
- ❌ **Folding Drawer 用旋转/折叠 3D 效果** → 用户实测反馈：千层酥视觉必须纯抽拉，旋转显得廉价
- ❌ **Folding Drawer 末位卡 opacity 0** → 千层酥的核心是「边缘可见」，末位保留 ≥ 0.18
- ❌ **Folding Drawer 书签做独立列表** → 失去「从卡延伸出来」的物理感；书签必须是 .card 子元素，跟着 transform 走
- ❌ **JS 劫持 touchmove 手写滚动/翻页** → 惯性丢失 + 掉帧；原生滚动 + scroll-snap 白送的手感
- ❌ **拖拽跟手阶段开着 CSS transition** → 永远慢半拍；pointerdown 先 `transition: none`
- ❌ **手势判定只看位移不看速度** → 快速轻扫无反应，「失灵」感；必须速度+位移双判定
- ❌ **push/pop 导航只有新页动** → 一眼 Web 味；双层同动（新页滑入 + 旧页 -25% 视差）是灵魂
- ❌ **手势做唯一入口**（无返回按钮/无可见操作按钮） → 可访问性崩 + 新用户找不到路
- ❌ **整个 sheet 设 `touch-action: none`** → 内容区没法竖向滚动；只在 handle 区禁
- ❌ **滑动操作无互斥** → 多行同时展开，界面失控
- ❌ **高频触感震动** → 蜂鸣器既视感 + 耗电；只在状态改变瞬间震
- ❌ **内滚容器漏 `overscroll-behavior: contain`** → 滚到头传染给页面，用户「被甩走」
- ❌ **橡皮筋 1:1 跟手无阻尼** → 没有重量感；对数阻尼公式 `c*(1-1/(dx/c+1))` 是灵魂
- ❌ **Pinch 的 transform-origin 固定 center** → 缩放围绕中心转，手指位置「漂移」，一眼假
- ❌ **拖拽排序换位实时 insertBefore** → 每次换位整表重排闪烁；让位 transform 预览，松手结算
- ❌ **fling 速度取整段平均** → 起手慢稀释末速；只取 release 前最后 3~5 个 move
- ❌ **堆叠卡片后层不跟进** → 看不出「一叠」；前层进度 ×2 让后层提前就位
- ❌ **液态按钮前沿是直线** → 那是普通进度条；贝塞尔凸起 + 速度响应才是「液态」
- ❌ **stretch 头图 origin 在 center** → 底部露缝；origin 必须 `50% 100%`
- ❌ **手势做唯一入口**（pinch/排序/刷新无按钮等价物） → 可访问性崩，见补充律 7
- ❌ **双击爱心从卡片中心冒出** → 违反「反馈从触发点长出来」（补充律 8）；用第二击坐标
- ❌ **横滑通知飞走后留洞** → 高度坍缩必须做；洞不合上列表视觉断裂
- ❌ **滚轮手写惯性** → 原生 snap 滚动的惯性最顺；自绘掉帧还失手感
- ❌ **主题揭示起点在屏幕中心** → 失去因果感；从按钮坐标扩散
- ❌ **pointercancel 当成功处理（语音发送）** → 来电中断发半句话，事故级 bug
- ❌ **骨架屏尺寸是猜的** → 内容到达瞬间布局跳动 —— 骨架的全部意义就是消抖
- ❌ **常规成功也撒花** → 庆祝通货膨胀；每用户流 ≤1 处（补充律 9）

### 6.2 错配缓动

- ❌ **`linear`** → 机械感，绝不用在主交互
- ❌ **用 `cubic-bezier` 模拟弹性** → 永远达不到真正的 elastic 那种过冲感
- ❌ **`ease-in`**（开头慢）于入场动画 → 用户等待感变长
- ❌ **持续时间 > 1.5s 的入场动画** → 用户失去焦点
- ❌ **持续时间 < 150ms 的反馈动画** → 看不见

### 6.3 错配叠加

- ❌ **同一屏 > 4 个动效源** → 视觉混乱
- ❌ **滚动驱动 + 指针驱动同时作用同一元素** → 互相干扰
- ❌ **glassmorphism + parallax 同一层** → blur 重计算，性能崩溃

## 8. 性能与无障碍预算

### 7.1 性能预算

| 设备等级 | 同时运行动效 | 持续时长上限 | 避免 |
|---------|------------|------------|------|
| **高端桌面** | ≤ 4 个 | 无限制 | — |
| **中端手机** | ≤ 2 个 | ≤ 600ms | blur > 20px、3D 倾斜 |
| **低端机 / 微信小程序** | ≤ 1 个 | ≤ 400ms | SVG 复杂路径、blur > 12px |
| **iOS Safari** | ≤ 3 个 | ≤ 800ms | backdrop-filter 过深 |

**性能铁律**：
- 只动画 `transform` 和 `opacity`（GPU 加速）
- 不要动画 `width/height/top/left`（layout 重排）
- `filter: blur()` 也要慎用，会重绘
- 长列表用 `will-change: transform` 但要及时移除

### 7.2 无障碍（必须遵守）

```javascript
// 必须：监听 prefers-reduced-motion
const motionQuery = window.matchMedia('(prefers-reduced-motion: reduce)');
if (motionQuery.matches) {
  // 跳过所有动效，直接显示 final state
  return;
}
```

| 视差 | 静态背景层 |
